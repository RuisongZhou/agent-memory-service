我要把你保存的记忆迁移到另一个记忆服务。请列出你为我保存的所有记忆，以及你从过去的对话中了解到、和项目 {project} 有关的信息。

要求：
1. 只输出一个代码块。每条记忆占一行，是一个 JSON 对象。代码块外不要写别的内容。
2. 字段：
   - text：记忆内容。尽量保留原话，一条只写一件事。
   - kind：preference（我的偏好，包括我要求你怎么做）、fact（事实或决定）、reference（去哪里找信息）之一。
   - date：保存或得知的日期，格式 YYYY-MM-DD，不知道就留空。
   - source：来自哪个记忆文件；来自对话就写 conversation。
   - scope：只和这个项目有关写 project，跨项目适用写 global。
3. 不要合并、归纳、改写或省略条目，也不要补充你不确定的内容。
4. 不要输出密钥、令牌、密码等凭据，遇到时写成 [redacted]。
5. 不要输出健康和心理状况、财务数额、证件号码、住址和私人电话、家人或伴侣的名字等个人敏感信息。
6. 超过 100 条时分几次输出，每次的最后一行写 {"continued": true}，等我回复"继续"再输出下一部分。
